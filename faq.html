Setup & help

Frequently asked questions.

Clear answers for organizers, players, purchasers, and server owners.

Setup & permissions

How do I set up the bot?

Add the bot, run /setup with Manage Server permission, and choose your channels or automatic channel creation. See the complete setup guide.

Who can use the controller?

Setup and controller tools require Manage Server. The key-revocation control is restricted to the configured bot owner.

Can regular members see private match rooms?

No. Only the two competing teams and authorized administrators can see their temporary match text and voice channels.

Events

Can I use fewer than 16 teams?

Yes. Brackets support 2–16 complete teams and automatically add byes when needed.

Does the bot process player payments?

No. Organizers choose payment methods and manually confirm who has paid. The bot tracks status but never handles money.

Does it need a separate database?

No. SQLite is built in. Hosts should use persistent storage so records survive redeployments.

Premium & Lifetime

How does the free 15-day trial work?

An administrator votes on Top.gg, then opens /setup → Premium and selects Verify Vote & Start Trial. Each server can claim it once.

How does the purchaser transfer Lifetime Premium?
  1. Add the bot to the new server.
  2. The original purchaser gets Manage Server permission there.
  3. Run /setup and open Premium.
  4. Select Assign My Lifetime License.

The old server returns to Free immediately. Only the original purchaser can transfer the license, one server can use it at a time, and transfers are limited to once every 30 days.

Can a redeemed Lifetime key be transferred?

Yes. The account that redeems it becomes the owner and follows the same one-server and 30-day transfer rules.

What should I do with activation and revoke keys?

Send only the activation key to the customer. Keep the paired revoke key private. Only the configured bot owner can use the Revoke Key control.
