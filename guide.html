Organizer guide

From install to champion.

Follow the event flow below. All tournament administration happens through buttons and forms.

01

Install and run setup

Add the bot, give it the requested permissions, run /setup, then choose existing channels or let Switcharoo build a secured event category.

02

Create the event

Open the private controller, select Create Event, and enter the event name, signup format, fees, and optional payment methods.

03

Open registration

Players register from the signup message using solo or duo signup. Close registration when the roster is ready and confirm payments if the event has an entry fee.

04

Reveal and adjust teams

Randomize the paid roster. During the reveal period, admins can Lock squads, Respin unlocked squads, or Nuke every team. Changes update live.

05

Create the bracket

The bot generates a visual single-elimination bracket and opens private text and voice rooms visible only to each matchup's two teams and administrators.

06

Confirm results

One player from each team confirms the submitted winner and score. An administrator approves the result before the bracket advances.

07

Close the event

After the final, select Close Event. Switcharoo removes temporary match resources and clears the active event panels.
