Setup & help

How to use Switcharoo.

From installing the bot to transferring Lifetime Premium, these are the steps organizers need most.

Getting started

How do I set up the bot for the first time?
  1. Add OMG Switcharoo to your Discord server.
  2. Give the bot the requested channel and messaging permissions.
  3. Run /setup as a user with Manage Server.
  4. Choose your existing signup, bracket, teams, controller, and transcript channels—or let the bot create a secured category automatically.
  5. Finish setup, then use the private controller panel to create your first event.
How do I run a complete event?
  1. Select Create Event in the controller and enter the event format, fees, and optional payment methods.
  2. Publish signups and close registration when the roster is ready.
  3. Mark paid players when payment is required, then randomize teams.
  4. Use Lock, Respin, or Nuke during the team-reveal period.
  5. Create the bracket. The bot opens private match rooms for each matchup.
  6. Both teams confirm each score; an administrator approves it before the winner advances.
  7. Select Close Event when finished to clean up temporary event resources.
Who can use the controller?

The setup and controller tools require Manage Server. Player-facing signup and match controls only appear where needed. The private key-revocation control is restricted to the bot owner's configured Discord account.

Events & privacy

Can regular members see private match rooms?

No. Only members of the two competing teams and authorized administrators can see their temporary match text and voice channels.

Can I use fewer than 16 teams?

Yes. Single-elimination brackets support 2–16 complete teams and automatically add byes when the team count is not a power of two.

Does the bot process player payments?

No. Organizers choose their accepted payment methods and manually confirm who has paid. The bot tracks payment status but never handles the money.

Does the bot need a separate database?

No. SQLite is built in and created automatically. Hosts should keep the database on persistent storage so event records survive restarts and redeployments.

Premium, trials & Lifetime

How does the free 15-day trial work?

A server administrator votes for OMG Switcharoo on Top.gg, then opens /setup → Premium and selects Verify Vote & Start Trial. Each server can claim the 15-day League Pro trial once.

How does a purchaser transfer Lifetime Premium?
  1. Add the bot to the new Discord server.
  2. The original purchaser must have Manage Server permission there.
  3. Run /setup and open Premium.
  4. Select Assign My Lifetime License.

The license moves to the new server immediately and the previous server returns to Free. Only the original purchaser can transfer it, only one server can use it at a time, and another transfer is allowed after 30 days.

Can a redeemed Lifetime activation key be transferred?

Yes. The Discord account that redeemed the Lifetime key becomes its owner and can use Assign My Lifetime License under the same one-server and 30-day transfer rules.

What should I do with activation and revoke keys?

Send only the activation key to the customer. Keep its matching private revoke key secure. Only the configured bot owner can see and use the Revoke Key control.
