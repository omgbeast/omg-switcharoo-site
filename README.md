# OMG Switcharoo website

Static website for GitHub Pages. It includes the landing page, pricing, Terms of Service, Privacy Policy, and Refund Policy.

## Before publishing

Open `script.js` and replace `ADD-YOUR-SUPPORT-EMAIL` with the public support email you want customers to use. The Discord install URL is already connected to the bot link from the main OMG Switcharoo README.

Premium checkout links open the published Discord SKUs. Review the legal pages for your business and location; they are a practical starting point, not legal advice.

## Publish with GitHub Pages

1. Commit and push these files to the repository's `main` branch.
2. On GitHub, open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select `main`, choose `/ (root)`, and click **Save**.
5. GitHub will show the public website URL after deployment.

Use these public URLs in the Discord Developer Portal:

- Terms: `https://YOUR-GITHUB-USERNAME.github.io/omg-switcharoo-site/terms.html`
- Privacy: `https://YOUR-GITHUB-USERNAME.github.io/omg-switcharoo-site/privacy.html`
